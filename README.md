# wow-wotlk-raid-point-manager
Raid Points Manager v1.17
World of Warcraft 3.3.5a — TrinityCore

**A simple addon for tracking player points and rounds in raids or custom groups.**
1. Opening the Addon
- Type /rp to open or close the addon.
- Use the minimap icon to open the interface.
2. Player Rosters
- Raid Roster — Automatically displays raid members.
- Manual Roster — Add players by name or by targeting them.
- Delete — Remove a player from the manual list.
- G1–G8 — Assign custom groups in Manual Roster.
- Sorting — Sort players by name, group, points, or rounds.
3. Awarding Points
- 0 / +1 / +2 / +3 — Select points for the current round.
- Click again — Deselect the selected points button.
- Next Round — Apply selected points and advance the round.
- Custom Amount — Enter any number and click + Add or - Remove to adjust points immediately.
- Reset — Reset an individual player's points.
- Reset All — Reset all players' points.
4. Announcing Results
- Announce /raid — Send results to raid chat.
- Announce /y — Yell the results.
- Announce /s — Send results to say chat.
5. Settings
Click Settings to customize the interface.
- Change background transparency.
- Choose background colors and textures.
- Select different fonts.
- Settings are saved automatically.
Important Notes
- Selected points are applied when clicking Next Round.
- Custom point adjustments are applied immediately.
- Raid Roster and Manual Roster share player point data.
- Player points and settings are saved between sessions.
Raid Points Manager — Simple, fast, and convenient raid point tracking!
